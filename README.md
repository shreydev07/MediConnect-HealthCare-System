
**MediConnect** is a robust and interactive web application developed to modernize and streamline hospital operations. Originally designed for **Highway Hospital, Sitapur Road, Lucknow**, this system digitizes traditional manual processes to ensure seamless data flow and secure handling of patient and administrative information.

## 🌟 Project Objectives

The primary goal of MediConnect is to provide a centralized and automated platform that ensures:

* 
**Centralization:** A unified system for smooth communication between doctors, staff, and patients.

* 
**Efficiency:** Seamless management of admissions, discharges, billing, and appointments.
* 
**Security:** Secure and efficient handling of all hospital records and patient data.

* 
**Automation:** Real-time generation of reports and data analytics for hospital performance monitoring.



## 🚀 Key Modules

The application is built with specialized modules to handle every facet of hospital management:

* 
**Admissions/Discharges/Transfers (ADT):** Tracks patient movements with real-time updates.


* 
**Accounts & Billing:** Manages automated invoice generation, payment processing, and insurance claims.


* 
**Pathology & Radiology:** Schedules and records results for medical tests, X-rays, MRIs, and CT scans.


* 
**Medical Stores & Pharmacy:** Maintains detailed inventory, medicine tracking, and stock replenishment alerts.


* 
**Communication Hub:** Facilitates internal notifications and telemedicine support features.



## 🛠️ Technology Stack

* 
**Frontend:** HTML5, CSS3, JavaScript, Bootstrap.


* 
**Backend Framework:** Python (Django).


* 
**Database:** SQLite3.


* 
**Development Environment:** PyCharm IDE.



## 📂 System Design

The system employs a modular architecture with role-based access control:

* 
**User Authentication:** Secure login/registration with separate portals for Doctors, Staff, and Administrators.


* 
**Functional Breakdown:** Integrated data flow between the User Module, Patient Management, Billing, and Inventory.



## 🔧 Installation & Setup

1. **Clone the Repository:**
```bash
git clone https://github.com/shreydev07/MediConnect-HealthCare-System.git
cd MediConnect-HealthCare-System

```




3. **Install Dependencies:**
```bash
pip install -r requirements.txt

```


4. **Apply Database Migrations:**
```bash
python manage.py makemigrations
python manage.py migrate

```


5. **Run the Application:**
```bash
python manage.py runserver

```
